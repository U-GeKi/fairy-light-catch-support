# ミリュフィのひかり集め サポートサイト

スマートフォン向けゲーム「ミリュフィのひかり集め」の日本語サポート情報とプライバシーポリシーを公開するための静的Webサイトです。ゲーム本体のソースコードはこのリポジトリに含まれません。

公開予定URL：<https://u-geki.github.io/fairy-light-catch-support/>

## ファイル構成

- `index.html`：トップページ
- `support.html`：遊び方、よくある質問、不具合報告、問い合わせ案内
- `privacy.html`：プライバシーポリシー
- `styles.css`：全ページ共通スタイル
- `assets/app_icon.png`：アプリアイコン、favicon、Apple Touch Icon
- `.nojekyll`：Jekyll処理を無効化する空ファイル

## ローカル確認方法

リポジトリ直下で簡易HTTPサーバーを起動し、ブラウザで表示します。例：`python -m http.server 8000` を実行後、`http://localhost:8000/` を開きます。HTMLファイルを直接開いても基本表示は確認できます。

## GitHub Pages公開手順の概要

内容とプレースホルダーを確認後、変更を手動でコミット・pushし、GitHubのリポジトリ設定からPagesの公開元ブランチとルートを選択します。本リポジトリはJekyllテーマを使わず、そのまま静的HTML/CSSとして公開する前提です。

## 公開前に必要な作業

- `[問い合わせ先メールアドレス]` の差し替え
- `[施行日]` と `[最終更新日]` の差し替え
- `[対応OSバージョン]` と `[アプリバージョン]` の差し替え
- 実機とスマートフォンブラウザでの最終確認

Gitコミットとpushは自動では行わず、内容確認後に手動で実施してください。
